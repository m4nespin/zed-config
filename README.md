# Zed Config

My personal Zed config files.

## Contents

- `settings.json` - portable Zed preferences.
- `AGENTS.md` - agent instructions used by Zed.

## Extensions

- Bearded Theme (`bearded-theme`) 1.0.0
- Dockerfile (`dockerfile`) 0.2.0
- HTML (`html`) 0.3.1
- Material Icon Theme (`material-icon-theme`) 1.3.1
- SQL (`sql`) 1.1.7
- TOML (`toml`) 1.0.3
- XML (`xml`) 0.1.0

## Themes

- UI theme: Bearded Theme HC Ebony
- Icon theme: Material Icon Theme

## Usage

Clone or copy these files into your Zed config directory.
